## 3. 공개 문서의 정합성

README와 설명 문서의 내부 링크·이미지 경로, SVG의 XML·ID 참조와 구성 수치를 확인했습니다.<br>
12개 SVG는 필요한 이미지 데이터를 내부에 포함하며 JavaScript·외부 폰트·외부 이미지 요청을 사용하지 않습니다.<br><br>

| 확인 항목 | 확인한 범위 |
|---|---|
| 원본과의 대조 | 기준 리비전, 주요 파일 23개, 패키지 버전과 기기별 배치 수 |
| 도식 구성 | 갤러리 모델 12종의 순서, 흐름의 연결 대상과 방향, 연락의 결과 분기 |
| 가로·모바일 | 표시 폭에 맞는 SVG 선택, 이미지 로딩, 글자 경계와 카드 정렬 |
| Hero | 글로우 이동, 마침표 바운스와 6.65초 반복 |
| 갤러리·경험 흐름 | 모델·단계의 순차 강조와 반복 |
| 아키텍처·연락 흐름 | 전송 방향의 점선 이동, 검증 화살표와 양쪽 결과 카드까지의 연결 모션 |
| 모션 감소 | SVG를 직접 열었을 때 애니메이션 중지와 기본 정보 유지 |

전송 점선은 색·굵기·불투명도와 화살표 머리를 고정하고 점선 위치만 이동합니다.<br>
연락의 결과 분기선은 화살표 머리 없이 성공·오류 카드까지 이어집니다.<br>
GitHub 게시 화면에서도 가로·모바일의 이미지 로딩과 도식의 반복 재생을 확인했습니다.<br><br>

모션 감소 검사는 SVG를 직접 연 상태에서 수행했습니다.<br>
Chrome의 미디어 에뮬레이션은 `<img>` 안의 SVG에는 전달되지 않아, 임베드 상태의 모션 감소까지 통과한 것으로 세지 않았습니다.<br>
글의 의미는 파일 해시만으로 판정할 수 없어, 구현 설명도 원본 코드와 별도로 읽고 대조했습니다.<br>
