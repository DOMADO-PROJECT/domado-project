## 실제 구현에서 가져온 시각 자료

이 저장소의 3D 아이콘은 원본 코드의 `models.js`와 `air-model.js`를 Three.js로 렌더링한 이미지입니다.<br>
별도 모델을 생성하거나 다른 서비스의 3D 파일을 가져오지 않았습니다.<br>
사이트 캡처와 문서용 재구성 이미지는 아래처럼 구분합니다.<br>

| 공개 자료 | 내용과 제작 조건 |
|---|---|
| `assets/diagrams/*.svg` | 실제 모델의 렌더링과 글자 이미지를 내부에 포함한 12개 도식 · 가로와 모바일 각 6개 |
| `assets/screenshots/entry.png` · `contact-card.png` | 실제 입장 화면과 연락 카드 · 1440 × 900 |
| `assets/screenshots/mobile-universe.png` · `mobile-project.png` | 모바일 공간과 DOMADO 소개 카드 · 390 × 844 터치 에뮬레이션 |

3D 렌더링에는 메인과 같은 ACES 톤 매핑, 노출 0.95, 환경 강도 0.4와 조명 구성을 사용했습니다.<br>
각 모델을 직교 카메라 범위 ±1.8에서 중앙에 맞췄으며, 회전은 `(0.22, -0.38, -0.10)`입니다.<br>
냄비는 내부가 보이도록 X축 회전을 0.52로 조정했습니다.<br>
재질·형상은 실제 코드이며, 카메라와 배치는 문서에 맞춘 별도 렌더링입니다.<br><br>

갤러리는 모델과 설명을 모두 표시하면서 DOMADO부터 연락하기까지 한 모델씩 움직입니다.<br>
각 모델의 동작은 2.4초, 다음 모델까지의 간격을 포함한 순서는 3초이며 전체 36초로 반복합니다.<br>
신호등 점등·모니터 파형·서버 팬·시계 화면·냄비 김·카드 삽입·비행기 날갯짓은 원본 모션을 사용했습니다.<br>
토마토의 움직임, teum의 펼침, WORLD의 뜀, GitHub와 벨로그 코인의 회전은 형태를 보여주기 위한 문서용 연출입니다.<br>
비행기의 전진과 모델별 재생 순서·속도도 문서에 맞춰 구성했습니다.<br><br>

워드마크는 원본의 Futura Condensed Extra Bold와 시스템 서체 조합으로 렌더링했습니다.<br>
두 줄의 글자 마스크 위로 반사광을 이동시키고, Neo둥근모 마침표의 형태·색과 바운스·회전을 SVG로 옮겼습니다.<br>
원본 제목의 6.65초 반복 주기, 반사광 2초·마침표 5.7초 시작 지연과 키프레임을 유지했습니다.<br>
폰트 파일은 이 공개 저장소에 포함하지 않았습니다.<br>
문서 SVG의 한글은 시스템 글꼴로 표시하므로 기기에 따라 글자 모양이 조금 다를 수 있습니다.<br>

## 도식을 읽는 방법

| 도식 | 설명하는 것 | 해석 범위 |
|---|---|---|
| `hero` | 실제 모델이 브랜드 주변에 펼쳐지는 첫인상 | 2D 배치·모션으로 재구성. 라이브 WebGL 장면이나 화면 녹화가 아님 |
| `project-gallery` | 프로젝트 9종·채널 2종·종이비행기의 개별 모델과 순차 동작 | 원본 모델과 모션에 문서용 연출을 더한 렌더링 |
| `experience-flow` | 입장 → 브랜드 전환 → 탐색 → 소개와 연락 | 패널의 순차 강조는 이용 순서를 설명하며 실제 진행률·대기 시간이 아님 |
| `architecture` | 정적 배포, 브라우저 모듈, 외부 서비스 | 핵심 역할을 묶어 표현. API 서버·DB를 추가한 구조가 아님 |
| `render-budget` | 데스크톱·모바일에 맞춘 장면 밀도와 해상도 상한 | 화면 폭으로 구분한 렌더링 설정 |
| `contact-flow` | 검증 → 요청 → 성공·실패와 입력 보존 | HTTP 응답 기준 상태. 실제 수신함 도착률이 아님 |

모든 도식에 가로와 모바일용 세로 버전을 제공합니다.<br>
README의 `<picture>`가 표시 폭에 맞는 버전을 선택합니다.<br>
본문 도식은 흰 배경, 검정 토마토와 브랜드, 회청색 영문 분류, 우측 설명과 가는 구분선으로 통일했습니다.<br>
브랜드 심볼은 글자 아래에 맞춰 배치했습니다.<br>
경험 흐름은 가운데 정렬한 네 패널을 이용 순서대로 하나씩 강조합니다.<br>
아키텍처는 브라우저 안의 `main.js`와 세 역할을 묶고, Vercel·EmailJS는 경계 밖에 놓았습니다.<br>
내부 관계는 머리 없는 선으로 연결하고, 정적 파일 로드와 연락 전송에만 방향을 표시했습니다.<br>
연락을 보낼 때 사용하는 EmailJS 경로는 전송 방향으로 흐르는 점선으로 구분했습니다.<br>
전송 점선은 색과 굵기를 유지한 채 이동하며, 머리에도 별도 강조를 주지 않습니다.<br>
로드·검증 통과의 화살표는 선의 강조가 끝에 도달하면 머리의 양쪽 획도 함께 강조합니다.<br>
Vercel Analytics는 기술 구성 표에 남기고 핵심 실행 도식에서는 생략했습니다.<br>
연락 흐름은 가로 화면에서 작성·전송·결과를 왼쪽에서 오른쪽으로 읽습니다.<br>
모바일에서는 작성·전송을 위에서 아래로 읽고, 같은 높이의 성공·오류로 나뉩니다.<br>
분기점과 결과에 닿는 선은 모두 화살표 머리 없이 이어지며, 전송 요청에서 양쪽 결과 카드까지 움직임이 이어집니다.<br>
두 갈래의 움직임은 가능한 응답 경로를 설명합니다.<br><br>

SVG는 이미지 데이터를 내부에 포함하며 JavaScript·외부 폰트·외부 이미지 요청을 사용하지 않습니다.<br>
SVG에는 모션 감소 설정을 따르는 스타일을 포함했습니다.<br>
애니메이션을 실행하지 않는 SVG 뷰어에서도 주요 정보가 기본 상태로 남습니다.<br>

## 화면 캡처 조건

| 화면 | 조건 |
|---|---|
| 입장 · 연락 카드 | 1440 × 900 · device scale factor 1 |
| 모바일 메인 · DOMADO 소개 | 390 × 844 · 터치·모바일 에뮬레이션 · device scale factor 1 |

기준 빌드는 원본 `c07175b`, 브라우저는 Chrome 156.0.8078.74입니다.<br>
메인 장면은 제목 전환을 기다린 뒤 `Space`로 움직임을 멈추고 캡처했습니다.<br>
로컬에는 Vercel Analytics 경로가 없어 캡처 중 분석 스크립트 요청을 빈 응답으로 대체했습니다.<br>
제품 코드와 화면 구성을 바꾸거나 사용자 데이터를 합성해 넣지는 않았습니다.<br><br>

공개 화면에는 연락처·초안·운영 데이터가 포함되지 않습니다.<br>
실제 이메일 전송, 외부 프로젝트 로그인, 원격 데이터 수정은 캡처에 필요하지 않아 수행하지 않았습니다.<br>

## 문서 스타일과 에셋의 출처

문서 흐름·단락의 `<br>`·도식 헤더·가로/세로 구성은 아래 세 공개 문서를 기준으로 맞췄습니다.<br>
작업 중 바뀌는 다른 수정본과 섞지 않도록 공개 리비전을 고정해 읽었습니다.<br>

| 참고 공개 저장소 | 대조한 리비전 |
|---|---|
| [DOMADO WORLD](https://github.com/DOMADO-PROJECT/domado-world) | `b10143a` |
| [피싱 신호등](https://github.com/DOMADO-PROJECT/phishing-signal) | `75892ed` |
| [teum.](https://github.com/DOMADO-PROJECT/teum) | `7207488` |

토마토·teum·피싱 신호등·WORLD는 기존 DOMADO 프로젝트의 심볼을 바탕으로 한 원본 구현입니다.<br>
GitHub·벨로그의 이름과 심볼은 해당 채널을 식별하기 위해 사용합니다.<br>
Watch·Recipe·Refactoring의 배지는 원본 프로젝트에서 사용한 로고를 응용했고, Realtime·On-Premises는 원본 브랜드 사이트에서 만든 형상입니다.<br><br>

공간 탐색의 디자인 참고는 [토스페이스 Universe](https://toss.im/tossface/universe)입니다.<br>
원본 사이트의 코드·모델을 배포하지 않으며, Three.js와 기존 브랜드를 바탕으로 별도로 구현했습니다.<br><br>

사이트 음악에는 [VSCO 2 Community Edition](https://github.com/sgossner/VSCO-2-CE/tree/440300901dfe9275fd84e0b7763af1f8443ae62e)의 CC0 샘플을 사용했습니다.<br>
원본 사운드 문서의 출처는 Versilian Studios, 오르간 녹음은 Simon Dalzell / Ivy Audio입니다.<br>
이 공개 문서 저장소에는 음원 파일을 포함하지 않습니다.<br>
