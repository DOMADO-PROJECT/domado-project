처음 보는 한 장면의 인상뿐 아니라 로고를 만지고, 누르고, 공간으로 들어오는 순서를 다듬었습니다.<br><br>

## AI와 함께 만든 범위

브랜드 사이트의 기획, 화면과 3D, 모션·사운드, 구현과 검증을 AI와 협업했습니다.<br>
시안을 만든 뒤 실제 화면과 입력을 반복해서 확인하고, 수정한 동작을 코드·테스트·문서에 맞췄습니다.<br>
작업 시간 절감률이나 AI의 기여율을 계량한 기록은 없습니다.<br><br>

이 사이트의 제작 범위와 사이트에서 소개하는 과거 프로젝트의 담당 범위는 구분합니다.<br>
예를 들어 Watch는 BLE 센서·앱 연동, Recipe는 데이터 수집·추천 API 연동 경험을 소개합니다.<br>
연결된 모든 프로젝트를 단독으로 전부 구현했다는 의미는 아닙니다.<br><br>
